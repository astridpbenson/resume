# Astrid Benson — Global Events, Strategy & Operations

A personal portfolio and print-ready résumé, published with GitHub Pages.

**Live site:** https://astridpbenson.github.io/resume/

## Portfolio at a glance

- 1,700+ events overseen annually across the Americas
- 2,800+ startups accelerated annually through the global innovation platform
- $3M in headcount managed
- An additional $10M in Americas event spend managed
- 4,000+ attendees at flagship Summit experiences
- Global event strategy and standards supporting 60+ offices

## Design & experience

The site is a responsive, accessible, research-inspired portfolio with:
- A clear leadership narrative and scale metrics
- Event portfolio formats and operating principles
- Selected operating outcomes and career timeline
- A print-optimized résumé (use **Download résumé** to print or save as PDF)
- No build step or third-party JavaScript dependencies

## Deployment

GitHub Actions deploys the `site/` directory to GitHub Pages on every push to `main`, and can also be run manually from the Actions tab.

## Local preview

Open `site/index.html` in a browser. For a local server, run:

```bash
python -m http.server 8000 --directory site
```
